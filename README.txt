划词翻译朗读

使用方法：
1. 用鼠标选中英文文字。
2. 按 Alt + Q。
3. 小窗口会显示原文和中文翻译。
4. 点击圆形播放按钮可用自然美式发音朗读，重复点击可停止。
5. 单独查询一个单词时会显示音标和星标按钮。
6. 浮窗右上角的 A− / A+ 可缩小或放大字号，调整后会自动保存。

顶部进度条会显示翻译和语音准备状态。翻译开始时会同时预生成语音，
相同内容会直接使用缓存，因此再次翻译或朗读会更快。

单词本：
- 点击翻译卡片右上角的齿轮，或按 Alt + Shift + S。
- “概览”显示本地累计词数和高频词；图表会隐藏 the、of 等常见虚词，但保留原始记录。
- “单词记录”可搜索历史、查看查询来源并筛选星标词。
- “拼写测试”会显示中文并播放读音，输入对应英文后检查答案。
- “设置”可选择自动翻译，也可配置 DeepSeek、Qwen 或 GLM 的 API。

退出后台：Alt + Shift + Q。

说明：翻译和自然语音需要联网；自动翻译不需要账号或 API Key，使用模型 API 则需自行配置密钥。
翻译内容只会在主动按下快捷键后发送给所选在线服务。词频、历史、星标和测试成绩
默认保存在本机 %LOCALAPPDATA%\SelectTranslate\data\word-history.db，也可在设置中更改数据目录。
单词本数据库不会随翻译请求上传。
